# 省 Token 技巧 · Codex 三法与上下文卫生

**日期**：2026-09-22
**来源**：小红书笔记《真正烧Token的10个习惯》（用户分享）+ 配图截图
**适用**：Codex / ChatGPT 桌面版；核心原则通用（WorkBuddy、MiniMax Code 同样适用）

---

## 核心思路

**不在 Codex 里做的事，就别让它消耗额度。**
一句话：前期讨论用 Chat，临时疑问用侧边栏，长对话定期压缩。

---

## 方法一：简单问题先在 Chat 里聊

- **场景**：执行任务前的方案讨论、写 PRD 文档等前期工作
- **做法**：先在 ChatGPT 桌面版的 Chat 模式完成（**不消耗 Codex 额度**），方案和文档定稿后，再移到 Codex 执行写代码的部分
- **操作路径**：ChatGPT 桌面版 → 右上角选 Chat → 完成讨论 → 左侧项目列表右击该对话 → 「在 Codex 中打开」→ 无缝迁移

## 方法二：临时问题用侧边栏问

- **场景**：用 Codex 干活时冒出的临时小疑问（比如不认识的术语）
- **做法**：不要塞进当前主对话，打开右侧侧边栏的临时聊天单独问
- **原理**：主对话上下文保持干净，旁支问题不会导致 token 膨胀

## 方法三：长任务做到一个阶段就压缩上下文

- **场景**：多轮对话后，讨论过程、旧方案、日志已经不再需要
- **做法**：输入整理提示词让它生成上下文摘要——只保留当前目标、关键决策、未解决问题和下一步行动，其余清理掉，后续 token 消耗大幅降低

### 📋 可直接复制的 Prompt（压缩上下文）

```
请整理当前任务上下文，清理失效方案、重复日志和无关历史，只保留当前目标、关键决策、核心约束、当前进度、未解决问题和下一步行动，后续基于最新摘要继续执行。
```

---

## 方法四：便宜额度起草提示词，GPT 只负责执行

- **场景**：要在 GPT 里生图、或让 GPT 按某个 Skill 分析文章/做任务时
- **做法**：先在 Codex / WorkBuddy（便宜或免费额度）里把提示词**写完整、改到位**，再复制到 GPT（贵额度）里只做"执行"——生图就生图、分析就分析，不让 GPT 反复帮你想提示词
- **原理**：起草提示词是最费 token 的环节（反复试、反复改）；把"想"放便宜端、"做"放贵端
- **关键约束**：若只需文字分析，就在提示词里写死「不要生图」，避免 GPT 自动跑图浪费额度

### 📋 可直接复制的 Prompt（文章分析 · 不生成图片）

```
# 角色
你是「文章拆解与知识提炼」专家。唯一任务：对用户下方粘贴的文章做结构化分析，全程只输出文字，禁止生成任何图片。

# 用户背景（分析时始终围绕它判断"是否有用"）
机械专业大一学生，正在全力冲绩点，目标保研清华/浙大；长期走"AI+机械"复合路线（软件工具 → 设备数据 → 具身智能）。一切分析最终要落到"对我下一步具体有什么用"。

# 分析流程（严格按顺序，四步）
## 1. 梳理结构
- 一句话概括文章核心主张
- 拆骨架：分几个部分/论点，各自讲什么

## 2. 提炼启发
- 列出最有启发的点，区分「通用道理」与「可直接落地的方法」
- 每条注明对应到用户背景里的哪件事

## 3. 尖锐提问
- 揪出文章没说清、自相矛盾、或值得深挖处，提 3~5 个问题
- 要"带刺"，逼人想清楚，不温和客套

## 4. 落点行动
- 翻译成"我下一步具体要做什么"的 1~3 条行动，越具体越好

# 输出要求
- Markdown 分层，信息密度高，禁止空话
- 全程文字，不生成图片
- 若文章缺失，先提示"请粘贴文章内容"，不自行编造

# 待分析文章（粘贴到下方）
```

---

## 一句话总结

**前期讨论用 Chat，临时疑问用侧边栏，长对话定期压缩，提示词起草放便宜端。**
把 Codex / GPT 的额度留给真正需要执行（写代码、生图、分析）的环节。

---

## 🐷 拍档批注（2026-09-22，猪皮）

这三招的本质是**「上下文卫生」**，不只 Codex 有效：

- **WorkBuddy**：前期闲聊、方案讨论别和长任务混在同一个会话里；阶段性让我「总结当前进度」——其实你的`会话状态.md`本来就是在做方法三（断点主题=摘要，下次会话接着跑）。
- **MiniMax Code**：同样适用——旁支疑问开新会话/侧边栏隔离；每个阶段收尾时把上面那段 prompt 原样丢进去压缩一次。
- 通用原则一句话：**上下文是钱，每一条旧消息都在替你付费。**
