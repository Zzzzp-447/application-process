# 系统读书协议（Echo × 康思淇）

> 用途：每次开一本新书，按本协议的三个阶段走；Echo 据此在每日共读时做费曼追问、在读后做知识库批注。
> 建立日期：2026-10-04。

## 总原则
- 一次一本书；每日共读 ≤15 分钟，**替代刷手机**，不叠加在现有任务（绩点 / 大创 / 40min 编程 / 高数错题）之上。
- 读书不为「读完」，为「把核心概念焊进自己的知识网」。
- 导图用 Obsidian simplemindmap 画（视觉化），但**给我看必须附一份缩进文本大纲**（见 Phase 1）——`.smm.md` 的层级是 base64 加密的，Echo 读不到树状结构，只看到一堆节点名。
- **读者背景校准（出题时必须带入）**：康思淇 = 机械大一，商科 / 金融 / 营销知识**基础为零**，但具备设计审美、产品直觉、强行动力。**所有问题默认从生活常识出发，不预设任何商业术语**；遇到术语，先翻译成大白话再问。

## Phase 0 定靶（开书前 · 基于目录）
你给：书名 + 为什么想读（想解决自己的什么问题 / 喂饱哪条线）+ **目录**（文字粘贴，或截图直接发在对话里；不要只给本地图片路径，Echo 读不到本地图）。
Echo 做：
1. 三问框选「攻坚点」：
   - 这本书对你哪条线有用？（保研 / AI+机械 / 产品思维 / 竞赛 / PAYATHON）
   - 你最想搞懂的 1-2 个底层问题是什么？
   - 哪部分最可能反直觉 / 最难啃？
2. **按章节出题**：针对目录的每个章节，提 2-3 个核心问题。每题标注类型，并遵守下方「出题四原则」。

   **出题四原则（Phase 0 按章出题时必须逐条满足）**
   - **① 难度校准（跳一跳够得到）**：默认从生活常识起跳，不预设商业术语；若用到术语先翻译成大白话再问。问题要让「商科零基础但聪明」的人踮脚能够到——既不能照抄书里定义（太浅），也不能直接抛专业模型（太深）。检验标准：你看到问题，能凭直觉先憋出一个粗糙答案，但需读完书才校准。
   - **② 批判性思维（必须每章至少 1 题）**：逼你质疑而非接受——问「这个方法有没有失灵的时候 / 反过来用会怎样 / 作者是不是漏了某类人 / 你身边有没有反例」。不止步于「理解」，要推向「边界与漏洞」。
   - **③ 实际生活锚点（保留，每章至少 1 题）**：读完能用它解释你真实遇到的场景——校园、家庭、刷到的短视频、PAYATHON 用户链路、大创团队互动都算。拒绝纯概念空转。
   - **④ 联系旧知（串回知识库）**：高数错题 / 峰哥聊机械 / 具身智能 / PAYATHON / 学长路径 / 李飞飞人才框架 / 影响力费曼笔记…凡是能缝上的都缝上，让一本书顶好几样用。

   题型标签（打在每题前）：
   - 💡 激发思考（先猜答案再看书，逼主动想）
   - 🔗 联系旧知（串回知识库）
   - 🛠 应用（读完能解释/解决真实问题 = 原则③）
   - ⚠️ 批判性质疑（原则②，每章必含）
   - ➕ Echo 补充（你没想到但重要的视角）
3. 定「达标线」：读完能用自己的话讲清哪几个概念、能举什么生活例子、能用在哪。

## Phase 1 章节费曼（读完一章触发 · ~10-15 min）
触发语：你说「**读完第 X 章**」+（可选）贴这章导图的缩进文本大纲。
⚠️ 节奏：先读后讲——**不要求每天打卡，读完一整章再找我开启费曼**，避免半懂就讲、碎片化。
Echo 做费曼循环（优先用 Phase 0 给这章预设的问题，再按你的回答临时追问）：
1. 从这一章里挑 1-2 个核心概念。
2. 让你用大白话讲 + 打个生活比方 + 说一个能用在哪。
3. 听你讲，对模糊处追问、给提示，不急着给答案。
4. 给一版「标准费曼讲解」（通俗类比 + 实际应用），并把概念**当场连到你的知识库**（每天锚定，不是读后才连）。
5. 标记概念状态：🔴待巩固 / ✅已应用。**不强制重复两次**——改为间隔检索：下次对话中一旦出现相关概念或问题，Echo 会再次让你讲，能在新情境下讲清即通关（间隔检索 > 重复练习，更贴大脑记忆规律）。

## Phase 2 读后总批注（读完 + 完整导图大纲）
你给：完整导图的缩进文本大纲。
Echo 做：
- 跨链接批注：指出「书里 X = 你知识库 Y 的底层逻辑」；
- 标注哪些内容可搬进竞赛 / 简历 / PAYATHON；
- 输出批注版大纲或单独读书笔记文件。
